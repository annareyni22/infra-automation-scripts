# Infrastructure Automation Scripts

This repository contains Bash and Python scripts used for infrastructure monitoring, operational automation, and troubleshooting.

## Topics Covered

* Disk Monitoring
* CPU Monitoring
* Memory Monitoring
* Log Analysis
* Service Health Checks
* File Cleanup Automation

## Technologies

* Bash
* Python
* Linux

## Purpose

The goal of this repository is to demonstrate practical automation skills commonly used in Linux administration, production support, DevOps, and platform engineering environments.
